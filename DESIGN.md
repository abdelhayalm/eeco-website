# eeco design system

Preserve the supplied eeco identity: solar yellow #FCBF01, green-black #111B1E, plum #26161F, navy #0D203B, deep blue #01111D, alabaster #FFFFF0. Quicksand for Latin; Noto Sans Arabic for Arabic. Original logos remain unmodified.

This is an incremental refinement of the existing agency/movement website. Product copy and the three-language content remain authoritative in source/copy.json. No certifications or measured results are implied.

## Implementation decisions

- Buildless static HTML/CSS/JavaScript, generated by build.py. Do not add React or Motion solely for decorative animation.
- The hero's curved plum surface, fine solar rings and supplied emblem express the existing brand. One short emblem gesture responds to pointer entry; no perpetual animation.
- Mobile navigation uses a consistent geometric SVG stroke family with translated visible labels. The selected section is marked by aria-current and solar contrast.
- Preserve complete project logos with object-fit: contain. Light surfaces support the original multiply treatment for Alquimia and Kemet.
- Reveal related project/stage elements with short staggered entrances. Service switches animate content, keeping panel geometry stable. Keyboard-initiated switches are immediate; animations on the same element cancel before replacement.
- Respect prefers-reduced-motion both initially and when changed during a session. Content must remain readable without animation or JavaScript.
- Preserve native controls, service-tab keyboard/RTL behavior, visible focus, the skip link and existing language persistence. No decorative numbering, arrows in buttons or GitHub footer link.

## Selected references

Impeccable: polish and accessibility review; Emil Kowalski: responsive press feedback, easing and interruptibility; Web Quality: accessibility and responsive verification. These are applied references, not installed project dependencies. Taste, Framer Motion, Vercel React and unrelated orchestrators are not required for this stack.

## Verification

Build validates translation coverage and asset resolution. Browser review covers 320/390/768/1280 frames, language selection, RTL, project images, mobile section navigation, service selection and keyboard operation. These checks are not a Lighthouse score or formal WCAG certification.
