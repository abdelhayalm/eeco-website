# eeco design system

Preserve the supplied eeco identity: solar yellow #FCBF01, green-black #111B1E, plum #26161F, navy #0D203B, deep blue #01111D, alabaster #FFFFF0. Quicksand for Latin; Noto Sans Arabic for Arabic. Original logos remain unmodified.

This is an incremental refinement of the existing agency/movement website. Product copy and the three-language content remain authoritative in source/copy.json. No certifications or measured results are implied.

## Implementation decisions

- Buildless static HTML/CSS/JavaScript, generated by build.py. Do not add React or Motion solely for decorative animation.
- The hero uses the supplied solar artwork and fine electron orbits. A short staggered welcome introduces the text; the existing slow orbit motion pauses outside the viewport and when the page is hidden.
- Mobile navigation uses a consistent geometric SVG stroke family with translated visible labels. The selected section is marked by aria-current and solar contrast.
- Preserve complete project logos with object-fit: contain. Light surfaces support the original multiply treatment for Alquimia and Kemet.
- Scroll entrances start just before viewport entry and stay readable throughout. Use a soft 16–22px independent translate rather than clipping or resizing cards, so hover transforms remain stable. Stagger only cards in the same desktop row; mobile entrances have no added delay. Already-visible content, deep links and fast scrolls settle immediately, and each entrance runs once.
- Butterfly wings use their own SVG artwork bounds as the animation origin. Service switches use a short entrance without replaying the active tab. Keyboard switches remain immediate, and pointer/focus interaction settles motion on the activated element.
- The three process illustrations have separate, continuing SVG motion: a caterpillar inching with a small segment wave, a cocoon swaying from its branch attachment, and a floating butterfly with wings hinged at the body. These CSS transforms stay separate from the scroll-entrance wrappers. IntersectionObserver runs only visible illustrations; hidden tabs, the local pause control and reduced-motion preferences stop the movement. The control has English, Portuguese and Arabic labels. Original illustration paths and the page layout are preserved.
- Interaction motion uses 160–360ms press, arrow, thumbnail and button feedback. Card images ease very slightly on hover. Native carousel scrolling handles slide transitions; captions settle in 180ms. No animation library or additional media is needed.
- Native dialogs enter in 320ms and close in 150ms, preserving Escape, backdrop dismissal and focus return. Animate opacity and transforms, never blur or dimensions. Mobile backdrops omit blur.
- Scroll feedback reads geometry before writing styles, scopes the progress variable to its bar, and only updates navigation attributes when the active section changes.
- Respect prefers-reduced-motion both initially and when changed during a session. Content must remain readable without animation or JavaScript.
- Preserve native controls, service-tab keyboard/RTL behavior, visible focus, the skip link and existing language persistence. No decorative numbering, arrows in buttons or GitHub footer link.

## Selected references

Impeccable: polish and accessibility review; Emil Kowalski: responsive press feedback, easing and interruptibility; Web Quality: accessibility and responsive verification. These are applied references, not installed project dependencies. Taste, Framer Motion, Vercel React and unrelated orchestrators are not required for this stack.

## Verification

Build validates translation coverage and asset resolution. Browser review covers 320/390/768/1280 frames, language selection, RTL, project images, mobile section navigation, service selection and keyboard operation. These checks are not a Lighthouse score or formal WCAG certification.
